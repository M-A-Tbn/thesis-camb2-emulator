# Figures for the current comparison

All images for this experiment live here. Numbers follow their order in the
[report](../Report.md). Each figure has a PNG copy for quick viewing or slides
and an SVG copy for resizing without losing sharpness.

| Filename, without extension | What it shows |
|---|---|
| `01_solver_agreement_by_redshift` | Maximum and RMS disagreement with CLASS for the three models across nine redshifts |
| `02_matter_power_flat_lcdm` | Flat LambdaCDM P(k): nine redshift panels, three solvers per panel |
| `03_matter_power_curved_lcdm` | Curved LambdaCDM P(k): nine redshift panels, three solvers per panel |
| `04_matter_power_evolving_dark_energy` | Evolving-dark-energy P(k): nine redshift panels, three solvers per panel |

The figures were moved here and renamed on 26 October 2026; their contents
were preserved byte-for-byte. The report links and analysis script use these
names, so regenerating the plots will keep this layout. Numerical data stay
in the parent results folder, and original solver records stay in raw/.
