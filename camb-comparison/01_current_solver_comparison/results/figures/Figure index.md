# Comparison figures

These are the figures used in the [report](../Report.md), in the same order.
Each is available as a PNG for viewing or slides and an SVG for resizing.

| Filename, without extension | What it shows |
|---|---|
| `01_solver_agreement_by_redshift` | Maximum and RMS disagreement with CLASS for the three models across nine redshifts |
| `02_matter_power_flat_lcdm` | Flat LambdaCDM P(k): nine redshift panels, three solvers per panel |
| `03_matter_power_curved_lcdm` | Curved LambdaCDM P(k): nine redshift panels, three solvers per panel |
| `04_matter_power_evolving_dark_energy` | Evolving-dark-energy P(k): nine redshift panels, three solvers per panel |

The first figure shows the differences between the solvers. The other three
show the power spectra themselves, with one panel for each redshift.
